How to solve this task.

Step 1
Take the switch (S1) and place on the table.
Step 2
Take the pc (PC-A) and place on the table.
Step 3
Take a console cable / or usb cable and plug into switch and pc. (To use console cable, right click S1 and click "inspect rear")
Step 4
Open PC-A - Goto Desktop - Press Terminal - Press OK.

Configuration Switch
---
enable
configure terminal
no ip domain-lookup
hostname S1
service password-encryption
enable secret class
banner motd # Unauthorized access is prohibited. #
!
vlan 99
!
interface vlan 99
ip address 192.168.1.2 255.255.255.0
ipv6 address 2001:db8:acad:1::2/64
ipv6 address fe80::2 link local
no shutdown
exit
!
interface range gigabitEthernet1/0/1-24
switchport mode access
switchport access vlan 99
exit
!
ip default-gateway 192.168.1.1
!
line console 0
logging synchronous
password cisco
login
exit
!
line vty 0 15
password cisco
login
exit
!
end
copy running-config startup-config
---
Configuration PC-A
---
Press PC-A - Press Desktop - Press Ip configuration
Set the following settings
IPV4 192.168.1.10
Subnet Mask 255.255.255.0
Default gateway 192.168.1.1
IPV6 address 2001:db8:acad:1::10
IPV6 prefix 64
IPV6 gateway fe80::1

Done
Now go back and connect the green "Copper straight through cable"
To PC-A ethernet port and S1 gigabitEthernet 1/0/6

Place Switch on rack

Pull cable from pc console port out and place on peg board again.
---
Shortcuts that can be used.
en -> Enable
conf t -> configure terminal
wr -> write
do wr -> do write
cp run start -> copy running-config startup config
int -> interface "interface id"
no shut -> no shutdown
int range -> interface range (useful for doing configuration of multiple ports with same configuration)
